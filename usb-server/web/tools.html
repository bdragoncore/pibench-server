🛠️ System Tools & Reverse SSH Host Access

Grant OpenCode AI and local processes instant SSH shell access back to your host machine without hardcoding credentials or IPs.

🔑 Host Authentication & SSH Key Exchange

To enable passwordless host command execution for AI, copy the Pi's public SSH key below into your host machine's ~/.ssh/authorized_keys:

Quick One-Liner Key Installers:

🐧 Linux / 🍎 macOS / 😈 FreeBSD (Bash / Zsh): 
mkdir -p ~/.ssh && curl -s http://{{.PiIP}}:8080/tools/pubkey >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys
🪟 Windows (PowerShell - OpenSSH Key Setup): 
if (!(Test-Path $HOME\.ssh)) { New-Item -Path $HOME\.ssh -ItemType Directory }; (Invoke-WebRequest -UseBasicParsing http://{{.PiIP}}:8080/tools/pubkey).Content | Out-File -FilePath $HOME\.ssh\authorized_keys -Encoding utf8 -Append

📦 Need to Install SSH Client/Server on Host?

🪟 Windows Package Manager (winget / PowerShell Admin): 
winget install Microsoft.OpenSSH.Beta # Or in Admin PowerShell: Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
🍎 macOS (Homebrew / System): 
brew install openssh # Or turn on Remote Login in System Settings -> Sharing
😈 FreeBSD / OpenBSD / NetBSD: 
pkg install openssh # sysrc sshd_enable="YES" && service sshd start
